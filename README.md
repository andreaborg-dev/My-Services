✨ Magical Pet Services — README
🐾 Overview
This website showcases a collection of magical‑themed pet services designed for all kinds of companions — from playful pups to mystical exotic creatures. Each service card includes a short description, an average price range, and a fallback image handler to ensure the UI always looks clean and polished.
The project is built using React, with services stored in a JSON file and displayed dynamically through reusable components.

✨ Features
- Magical‑themed service cards with images, descriptions, and pricing
- Automatic image error handling (fallback image if the original fails)
- Responsive layout using Flexbox
- Clean, readable component structure
- Easy to expand by adding new services to the JSON file

🧙 Services Included
- Pet‑Sitting
- Dog‑Walking
- Pet Food Delivery
- Pet Transportation
- Pet Playtime Sessions
- Exotic Pet Sitting
Each service includes a short magical description and an average price range.
